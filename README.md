# Enterprise Architecture Tool

A comprehensive web application for modeling, analyzing, and aligning IT systems with business strategy.

## Features

- **Dashboard Analytics**: Visual insights into your application portfolio, technical debt, and capability maturity
- **Application Management**: Full CRUD operations for managing your application landscape
- **Business Capabilities**: Track and manage business and technical capabilities
- **Project Tracking**: Monitor strategic initiatives and transformation projects
- **Interactive Charts**: Visualize architecture data with interactive charts and graphs

## Technology Stack

- React 18
- React Router for navigation
- Recharts for data visualization
- Lucide React for icons
- Vite for fast development and building

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This app is automatically deployed to GitHub Pages when changes are pushed to the main branch.
